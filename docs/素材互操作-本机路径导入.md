# 素材互操作 · 本机路径导入与工作流文件导入

> 需求：`req_7180b0d06a`（素材互操作增强）｜设计依据：`docs/墨盒-skill能力合并-重构设计.md` §4.3 / §9.3｜归属：墨盒 0.12.0

## 为什么做

以前把 skill / 本机产物搬进墨盒只有一条路：浏览器选文件 → base64 → RPC。

- 100MB 的视频 base64 之后是 133MB 的 JSON，又慢又容易顶到 RPC 上限；
- ComfyUI 的 9 个现成工作流在 `user/default/workflows/` 里，以前只能手工复制粘贴；
- 图片任务一次要导十几帧，逐张点选很费手。

现在宿主自己读盘：**给出本机路径就能导入**，格式按文件头识别（不信扩展名），工作流文件按
ComfyUI 的 `/object_info` 精确转成 API 格式并校验缺哪个节点。

## 一、协议（wire 增量，均为本地方法、零计费、不进 PAID_METHODS）

| 方法 | payload | result | 说明 |
|---|---|---|---|
| `importLocalPath` | `{ target, path, projectId?, jobId?, key?, kind?, name?, after? }` | `{ imported[], skipped[], kind, after? }` | 本机路径 / 目录导入 |
| `importWorkflowFile` | `{ path, offline? }` | `{ ok, workflow }` | 解析 ComfyUI 工作流文件 |

### `importLocalPath` 的 target

| target | 需要的 id | 接受 | 说明 |
|---|---|---|---|
| `project-source` | `projectId` | 图片 | 项目源图；落盘后走既有「换源图 → 作废派生」逻辑 |
| `project-video` | `projectId` + `key` | 视频 | `key=turn` 转圈视频（导入后自动抽候选帧），`key=<方向>` 某段行走视频 |
| `image-ref` | `jobId` | 图片 | 图片任务参考图（可目录批量） |
| `image-item` | `jobId` | 图片 | 图片任务产物（可目录批量） |
| `sequence-ref` | `jobId` + `kind` | 图片 / 视频 | `firstFrame` / `lastFrame` / `referenceImage` / `referenceVideo`（参考图 / 参考视频可批量） |

- `after`：`"none"`（默认）/ `"extract"`（导入视频后立刻抽帧）/ `"key"`（图片任务导入后本地抠像）。
- 目录批量：**不递归**、最多 200 个文件、不可识别的文件跳过并在 `skipped[].reason` 里写明原因；
  一个都没成功时直接报错（不伪装成「导入了 0 个」）。
- 字节落盘与作废逻辑**全部复用既有 upload* 入口**，所以产物与远端生成完全同形（`origin: "local"` 标注来路）。

### `importWorkflowFile`

- 收 **API 格式**与 **界面格式（`nodes` + `links`）**；
- 默认会读一次 ComfyUI 的 `/object_info`（只读、免费、不排队）做**精确转换**：
  按节点定义顺序消费 `widgets_values`，有连线的输入直接用连线；
  实测本机 9 个工作流（透明精灵 Turbo 13 节点）离线近似转换会丢 20 个控件值，
  精确转换后提示词（`5.prompt`）、模型文件名、尺寸都齐全；
- 校验「缺哪个节点」：`unknownNodes[]` 带节点 id 与 class_type（缺自定义节点时可定位）；
- `requiredModels[]` 列出工作流里引用的模型文件名；`bindings` 给出 `节点ID.输入名`；
- ComfyUI 不可达时自动退回离线近似转换，并把「可能丢控件值」写进 `warnings`（不静默）。

## 二、安全边界

- 只读**调用方显式给出的路径**；不做任何隐式扫描（不扫家目录、不扫全盘）；
- 目录导入由调用方显式给出目录，**不递归**子目录；
- 扩展名不可信：一切以文件头嗅探为准（PNG / JPEG / WebP / GIF / BMP / MP4 / MOV / WebM / AVI / JSON）；
- 体积上限：图片 30MB、视频 100MB、工作流 JSON 2MB；超限直接报错，不截断；
- 只写进墨盒自己的数据目录（`<DSH_HOME>/inkbox/`），不回写源路径。

## 三、界面入口

- 设置页「生图后端 → 本地 ComfyUI · 工作流库」：导入工作流时可直接填写 / 粘贴本机 JSON 路径；
- 模块② 图片生成：参考图与产物区提供「从本机路径导入」（支持目录批量）；
- 模块① 动画帧工具盒：源图 / 视频槽位旁提供「从本机路径导入」，与「选择本地视频」并列；
- 模块③ 序列帧生成：参考素材区同样支持路径导入。

（界面与协议同批交付；文案走 `T()` + `i18n-en.ts`。）

## 五、回滚

- 纯增量：旧 `upload*` 方法与语义一行未改；不导入就不走新路径；
- 两个新方法都是本地方法：不产生 receipt、不进 PAID_METHODS，回滚 = 移除方法注册即可；
- `scripts/e2e-interop-real.mjs` 依赖本机素材，缺素材时自报 SKIP（不伪装通过）。
